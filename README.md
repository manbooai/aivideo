## 安装说明 / Installation

1. **自动更新**：首次下载安装后，后续小版本更新与大版本升级均在应用内自动完成。
2. **Windows**：下载 `.exe` 安装包双击运行即可。若遇系统安全提示，点击 **「更多信息 (More info)」** → **「仍要运行 (Run anyway)」**。
3. **macOS**：打开 `.dmg` 后将 **「Manboo短剧」** 拖入 **「Applications（应用程序）」** 即可（首次打开若遇系统安全提示，在「应用程序」中右键点击应用图标选择 **「打开」**）。
