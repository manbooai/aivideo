## 安装说明 / Installation

1. **Windows**：下载 `.exe` 安装包双击运行即可。若首次运行弹出 Windows SmartScreen 提示（「Windows 已保护你的电脑」），请点击 **「更多信息 (More info)」** → **「仍要运行 (Run anyway)」**。
2. **macOS**：打开 `.dmg` 后将 **「Manboo短剧」** 拖入 **「Applications（应用程序）」** 文件夹。
   - **首次打开若弹出安全提示（「无法打开 / 未验证开发者」）**：
     - **方式一**：在「应用程序」中右键（或按住 `Control` 键点击）**「Manboo短剧」** 图标，选择 **「打开 (Open)」**。
     - **方式二（macOS 13 / 14 / 15+ 推荐）**：打开系统 **「系统设置 (System Settings)」** → **「隐私与安全性 (Privacy & Security)」**，向下滚动到底部「安全性」区域，点击 **「仍要打开 (Open Anyway)」** 即可。
3. **自动更新**：安装包已内置最新完整版本，新用户安装后即可直接使用；后续如有版本更新将在应用内自动完成。
